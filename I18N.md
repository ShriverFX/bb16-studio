# Localisation du site

Le français conserve ses URL racine. Les pages traduites sont générées dans
`/<locale>/` avec un `lang` BCP-47 exact, une URL canonique, des liens `hreflang`
réciproques et un sélecteur de langue utilisable sans JavaScript. L'arabe utilise
`dir="rtl"`. Aucune redirection imposée ni service de traduction côté navigateur.

## Périmètre

22 variantes, alignées sur ConvertAir et DocCipher : `fr en de es it pt pt-BR
nl pl ru uk tr ar hi id ja ko th vi zh zh-Hans zh-Hant`. Il s'agit de 19 langues
de base, avec variantes de portugais et de chinois.

Douze pages par variante : accueil, studio, catalogue, ConvertAir, DocCipher,
support, contact, confidentialité du site, mentions légales, politiques de
confidentialité ConvertAir/DocCipher et page 404. Les pages HGQ, ses procédures
juridiques et les deux formulaires privés de retour testeur restent français.
Les liens concernés portent la mention « Français ». HGQ et PeakSolo attendent
leur phase produit et leurs propres preuves, conformément à l'ordre demandé.

Les prix restent les références France en euros ; aucune conversion ou offre
Store régionale n'est inventée. Les liens Google Play dépendent toujours de
`store_listings.*.published`. La localisation ne rend aucune application publiée.
Les informations juridiques de l'éditeur qui manquent à la source restent
explicitement à confirmer dans chaque traduction.

## Sources et construction

`site_i18n.py` extrait des unités de phrase entières, y compris leur balisage
inline, des gabarits français de `build_site.py`. `locales/source.json` fige
402 unités. Chaque catalogue `<locale>.json` contient une traduction complète
de chaque unité. Les chaînes d'interaction hors gabarit sont dans `ui.json`.

La construction et la validation ne nécessitent que Python standard. Le
contenu traduit est statique dans le HTML ; il ne dépend ni d'une API ni de
JavaScript pour s'afficher. Une clé absente, un catalogue différent du source,
un balisage modifié ou un paragraphe manifestement laissé en français bloque
la construction. Les contrôles automatiques ne remplacent pas une relecture
linguistique humaine native ni une validation juridique.

Après une modification du texte français, actualiser explicitement le source
(`python site_i18n.py`), puis les traductions concernées. Ne pas régénérer le
source pour masquer un écart sans traduire les nouvelles unités.

```powershell
python build_site.py
python validate_site.py
python validate_i18n.py
python -m unittest -v test_site_gates.py test_i18n.py
npm test --prefix tests
python export_site.py --output _site
```

L'export utilise une liste explicite de pages et médias. Il n'inclut ni les
catalogues JSON, ni les scripts, ni les preuves, ni les documents de travail.
Un aperçu de chantier dans `_apercu/i18n-draft` n'est jamais un artefact de
publication ; seul le build complet alimente l'export.

## Médias par langue

Chaque page ConvertAir/DocCipher traduite référence ses propres fichiers
`assets/screens/<app>/<locale>/` et `assets/video/<app>/<locale>/`.
Les vidéos sont des animations de captures fixes, pas des démonstrations de
parcours réellement filmés. La préférence de réduction des animations et les
boutons de pause restent disponibles avec des libellés localisés.

- ConvertAir : cinq captures d'intégration historiques par variante, issues de
  `docs/poc/screenshots-gate6`. Les anciens réglages/paywalls retirés restent exclus.
- DocCipher : huit écrans des widgets réels rendus sur hôte par
  `tool/store_screenshots`, avec catalogue, coffre, caméra et offres fictifs.
  `FLAG_SECURE` reste intact. Les familles Noto de repli sont chargées uniquement
  dans le harnais hôte. Leur version exacte sur Android n'est pas attestée.
  Le prix affiché est la référence France de démonstration, pas une observation
  d'un achat ni d'un tarif régional réel.
- Le français conserve les médias déjà validés du site ; les nouvelles variantes
  sont des ajouts. Les PNG officiels des marques sont préservés.

L'import est une action explicite sur le poste source, indépendante du build :

```powershell
python scripts/make_localized_media.py convertair --output-root ../ConvertAir/docs/poc/screenshots-gate6 --evidence-dir C:/BB16/00_INBOX/site-i18n-20261013/media
python scripts/make_localized_media.py doccipher --output-root ../DocCipher/docs/store/screenshots-site-i18n --evidence-dir C:/BB16/00_INBOX/site-i18n-20261013/media
```

Les manifestes contiennent les hashes des sources et des dérivés. Les pixels
ne sont pas repeints pour traduire une interface. La géométrie du téléphone
reste celle de `product_pages.phone_frame()` pour tous les produits et langues.
La provenance versionnée des 546 nouveaux dérivés est conservée dans
`content/i18n-media-provenance.json`, avec chemins relatifs aux projets source.
Ce fichier de travail est exclu de l'export public.

## Vérification navigateur

`scripts/check_i18n_browser.cjs` utilise un Playwright local et un navigateur
local (`PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`). Il vérifie les langues,
directions, liens, ressources, erreurs JS, largeur mobile, géométrie des
téléphones, navigation clavier et sans JS, et absence de requêtes externes.
Les preuves et captures vont dans `_apercu/i18n-proof`, exclu de l'export.
La matrice complète couvre 264 rendus produit (22 variantes, deux apps, trois
largeurs et deux thèmes), 220 pages générales mobiles et les interactions dans
22 variantes. Les contrôles de poids incluent les feuilles/scripts de langue.

Une réussite locale ne prouve ni déploiement, ni langue relue par un locuteur
natif, ni comportement des applications sur appareil, ni conformité mondiale.
