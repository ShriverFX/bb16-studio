Site web

Confidentialité

Ce site est un site statique de présentation. Il est conçu pour fonctionner sans compte et sans outil d'analyse marketing.

Données du site

BB16 Studio ne place pas de cookie analytique, de pixel publicitaire ou de SDK de suivi sur cette version du site. Le choix du mode clair ou sombre est mémorisé uniquement dans le navigateur, sans transmission à BB16 Studio. Un hébergeur peut traiter les journaux techniques nécessaires à la distribution HTTPS ; ces journaux relèvent de son propre fonctionnement et de ses règles publiques.

Retours des testeurs

Les formulaires ConvertAir et DocCipher préparent un retour sur votre appareil. Les réponses ne sont pas envoyées automatiquement au studio. La mémorisation dans votre navigateur est facultative ; vous pouvez la désactiver ou réinitialiser le formulaire. Vous choisissez ensuite de télécharger le fichier ou de copier le résumé, puis de le transmettre à Lucas. Si vous le transmettez, le studio reçoit les informations que vous avez choisies pour comprendre votre retour. Utilisez un pseudo facultatif et des données fictives ; ne renseignez aucun PIN, mot de passe, secret ou document privé.

Contact

Si vous écrivez à bb16studio@gmail.com, l'équipe reçoit les informations que vous choisissez d'inclure pour répondre à votre message. N'envoyez pas de secret ou de document sensible.

Applications

Cette page concerne le site BB16 Studio. Les applications ont leurs propres données, services tiers et parcours de suppression. Pour ConvertAir, consultez la confidentialité ConvertAir ; pour DocCipher, la confidentialité DocCipher. Pour HGQ, la politique publiée par l'application est disponible sur la page de confidentialité HGQ.

La page de suppression HGQ du site reprend le parcours utilisateur connu et le canal de contact actuel.

Mise à jour

Cette page sera mise à jour lorsque l'identité légale, l'hébergement final ou les services du site changeront.
