Ouvrez DocCipher, utilisez uniquement des documents et coffres fictifs, puis indiquez ici ce que vous avez observé.

Pour chaque test : faites l’action dans l’app, vérifiez le résultat, puis choisissez « Pas encore testé », « Ça marche » ou « J’ai un problème ». Si une fonction est indisponible ou si Premium n’est pas fourni, choisissez « Pas encore testé » et précisez-le dans un commentaire.

Tests DocCipher

Préparez des documents de test marqués TEST. Pour la sauvegarde/restauration, saisissez le secret uniquement dans l’app : ne l’écrivez jamais ici.

Coffre leurre et configuration du code de panique (Premium, facultatif)

Si Premium n’est pas fourni, laissez « Pas encore testé ». Faites d’abord les essais du coffre leurre, puis configurez la panique sur des coffres fictifs. Ne renseignez aucun PIN ou mot de passe dans ce formulaire.

Déclencher le code de panique (Premium, facultatif et irréversible)
ATTENTION : saisir le PIN de panique armé à l’écran de déverrouillage supprime immédiatement les coffres choisis, sans nouvelle confirmation. Utilisez uniquement des coffres et documents fictifs jetables, après les essais du coffre leurre et de la configuration ci-dessus. L’effacement est logique ; les sauvegardes externes restent conservées. Ne faites jamais ces essais sur vos données personnelles.
Achat test et avis (facultatif)

Achat uniquement avec un compte de licence de test fourni par Lucas : aucune carte, aucun paiement. Un avis Google peut ne pas apparaître (carte ou délai de 90 jours) ; ne modifiez pas l’horloge et ne demandez jamais une note positive.
